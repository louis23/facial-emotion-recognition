# Facial Emotion Recognition App

A real-time facial emotion recognition system using a webcam, OpenCV, and a pre-trained deep learning model built with TensorFlow/Keras.

## 📸 Features

- Real-time face detection using Haar cascades
- Emotion classification from facial expressions
- Live video feed with emotion label overlay
- Easy to run from the terminal

## 🧠 Emotions Recognized

- Neutral  
- Happiness  
- Surprise  
- Sadness  
- Anger  
- Disgust  
- Fear  
- Contempt  
- Unknown
